(10)-(12), Lemma 2's two definitions Eqs. (16)-(17), the others belong to the proofs. The claims stated in prose without a number are rows of their own, named by section)

How CORA's `stl` class checks a formula on a reachable set: rewrite the formula to sampled time (Sec. 4.2, Table 1), bring it to conjunctive normal form, transform it to a formula on reach sequences (`Lemma 2`), and check that by a set inclusion per time point or interval. CORALean formalizes all of it: STL over traces, RTL over reach sequences, the sixteen rewriting rules of Table 1 each sound, their use in `Lemma 4` (every negation normal form has a sampled time formula implying it, scaled to a `c`-divisible formula), the normal form (`Sec. 4.1`), `Υ` on it with the proof that it is sound and complete (`Lemma 2`), the model checking theorem `Thm. 1` built from these, and the reduction of `Aϱ` to a polytope inclusion (`Sec. 5`). `Eq. 12` as printed is false, its `tsupp` hypothesis not deciding a formula; the equivalence for formulas decided by disjoint time sets is proved, and the instance for disjoint time blocks `Lemma 2` uses is `ForallExistsIffExistsForall`. Hybrid automata are not modelled; `Traces(S)` is any set of traces, and time is `ℝ≥0` as in the paper.

Formalizing the proofs found two hypotheses the statements need and the paper never states, and one statement that is false as printed (`Eq. 12`), each with a counterexample in Lean, below. CORA's `stl2rtl` already handles one of them: it groups the disjuncts by their next-operator, as `Lemma 2` needs.

## Findings

**`Eq. 10`, `Lemma 2` and `Sec. 3` need a state at every time.** The proofs build a trace through a given state by taking an arbitrary state of `R(t)` at every other time; if some `R(t)` is empty, `C(R)` is empty and every formula holds of it. `Eq. 10` then fails, for a `Υ` sound and complete for one reach sequence `R` with `R(1) = ∅`, `Υ(ϕ) = (C(R) ⊨ₜ ϕ)`: `Υ(⊥)` holds and `A ⊥` does not ([`UpsilonOfPform.lean`](../../src/CORALean/Specification/STL/Counterexamples/UpsilonOfPform.lean)). `Lemma 2` fails for `R(t) = Bool` except `R(5) = ∅` and the formula `X₀(F(0,1)⊥ ∨ ⊥)`, `R` finitely represented with the single breakpoint `5` ([`CNFUpsilonEmpty.lean`](../../src/CORALean/Specification/STL/Counterexamples/CNFUpsilonEmpty.lean)). The reach sequences of an actual system have a state wherever it has a trace, so the paper's setting excludes this; the formalization states it.

**`Eq. 12`'s `tsupp` hypothesis does not make the formulas independent.** The proof splices two traces violating `ϕ₁` and `ϕ₂` into one violating both, which needs `tsupp(ϕᵢ)` to decide `ϕᵢ`: traces agreeing on it agree on `ϕᵢ`. The single-change definition gives only that a trace is changed at one point at a time, so a property that no change of one point flips, but that changes with infinitely many (the true points of `(0,1)` are cofinal in it), has an empty `tsupp` and is not decided by it. STL expresses one, given a guard on the times past the window: `ϕ₁ = ¬X₁(p ∨ F(0,1) p) ∧ G(0,1) F(0,1) p` says `ξ` is false on `[1,2)` and every `t ∈ (0,1)` has a true `ξ(u)`, `u ∈ (t, t+1)`, hence `u < 1`; its `tsupp` is in `[1,2)`, the guard, while it depends on `(0,1)`. With `ϕ₂ = F(0,1) ¬p`, `tsupp(ϕ₂) ⊆ (0,1)`, the sets are disjoint. For the reach sequence that is `Bool` on `(0,1)` and `{false}` elsewhere, a trace true on all of `(0,1)` satisfies `ϕ₁` and any other satisfies `ϕ₂`, so `C(R) ⊨ₜ ϕ₁ ∨ ϕ₂`, but the all-false trace violates `ϕ₁` and the one true exactly on `(0,1)` violates `ϕ₂`: for a sound and complete `Υ`, `Υ(ϕ₁ ∨ ϕ₂)` holds and `Υ(ϕ₁) ∨ Υ(ϕ₂)` does not ([`UpsilonOr.lean`](../../src/CORALean/Specification/STL/Counterexamples/UpsilonOr.lean)). The equivalence holds when `ϕ₁`, `ϕ₂` are decided by disjoint time sets (`STL.upsilon_or_of_decided`), the hypothesis the proof uses; for formulas whose `tsupp` does decide them, which includes every one built without such cofinality, it is the printed one.

**`Lemma 2` needs the `j` of a clause to be distinct.** The normal form `⋁ⱼ X_c^j (ϕᵢⱼ ∨ ϱᵢⱼ)` has one disjunct per power of `X_c`. Two with the same `j` break completeness, since `Υ` does not merge them: `F(0,1) x ∨ F(0,1) ¬x` holds of every trace of `R(t) = Bool`, while `Υ` of it is `X_{1/2} A x ∨ X_{1/2} A ¬x`, false ([`CNFUpsilonDuplicate.lean`](../../src/CORALean/Specification/STL/Counterexamples/CNFUpsilonDuplicate.lean)). CORA's `aux_convertClause` groups the disjuncts by `from`, i.e. by `j`, before forming `ϱ'`, so it runs the merged formula and is right.

**`Table 1` has side conditions it does not print.** The rows `U[i,j]`, `R[i,j]` need `1 ≤ i ≤ j`, so that `i-1` and `j-1` are bounds, and the rows `U[0,j]`, `R[0,j]` need `1 ≤ j`; without them `j-1` is no bound at all. The last `F_I` row prints `F_I ϕ₁ R[0,j-1] ϕ₂`, the one place a parenthesis is missing; it is read as `F_I(ϕ₁ R[0,j-1] ϕ₂)`, like the other `F_I` rows, and that reading is the one the proof supports. All sixteen rows hold as implications `ϕ' ⇒ ϕ`, which is what the rewriting needs; none is claimed to be an equivalence.

**`Thm. 1`'s completeness is for sampled time formulas.** The text says the transformation is complete "if `ϕ` is equivalent to a sampled time STL formula". The rewriting of Table 1 is an implication `ϕ' ⇒ ϕ`, so the sampled time formula it produces can be strictly stronger than `ϕ`, and nothing printed says it is not when `ϕ` has an equivalent sampled time form; where `ϕ` already is one, no rewriting happens and `Lemma 2` and the normal form give an equivalence. That is what `STL.model_checking_complete_sampled` states. The soundness half is the one the verification needs, and holds for every `c`-divisible `ϕ`.
