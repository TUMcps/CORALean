# Reachability Analysis of Linear Systems with Uncertain Parameters and Inputs

M. Althoff, O. Stursberg and M. Buss. "Reachability Analysis of Linear Systems with Uncertain Parameters and Inputs". In Proc. of the 46th IEEE Conference on Decision and Control (CDC), 2007, pp. 726-732.

**Source:** https://mediatum.ub.tum.de/doc/1289985/728488.pdf (the authors' copy in the TUM repository, mediaTUM record 1289985, a 7-page PDF of the CDC'07 draft dated 17 September 2007, read in full; text extracted with PyMuPDF. The venue, pages 726-732 and doi:10.1109/CDC.2007.4434084 are from the repository's record.)  
**Inventory:** confirmed (Definitions 1-2, Lemmas 1-3, Theorems 1-4, Propositions 1-2, Algorithm 1 and Example 1, each with its own counter; equations (1)-(7); Figs. 1-4 and Table I; the examples are Sec. VII)

The paper behind the matrix exponential, the correction matrix and the input solution the
continuous-time linear reachability in CORALean is built on: the Taylor series of `e^{At}`
truncated at order `p` and widened by the remainder `E(t)` of Liou (1966), [16] in the paper,
under `ε = ‖A‖∞t/(p+2) < 1` (`Thm. 1`); the interval matrix `F` that widens the convex hull of
the start set and its image to the whole step (`Thm. 3`); the interval-matrix map of a zonotope
(`Lemma 2`, `Lemma 3`, `Thm. 4`); and the input solution (`Prop. 2`). Everything is stated for a
system matrix that is an interval matrix and may vary in time inside it. The tree formalizes
most of it at a single matrix, the degenerate interval, which is a part of each statement and so
leaves the row `—`; the interval-matrix results proved as printed are `Lemma 1` and `Thm. 4`.
Althoff's thesis (2010) reproduces this paper in its Sec. 3.2-3.3 and says it revises incorrect
parts of it; `Prop. 2` is one (see Findings).

## Findings

**`Lemma 1` — the vertex branch.** The lemma carries no hypothesis on `t` beyond the section's
`t ∈ ℝ⁺`, and at `t = 0` its `-1/t` branch returns `-½` where `γ(a) = at + ½a²t²` is constantly
`0`: sound, but not the exact value the lemma claims. The formalization proves the enclosure at
every `t` and the attained bounds at `t ≠ 0`.
[`ExpIntervalWAttained.lean`](../../src/CORALean/ContDynamics/LinearSys/MatExp/Theorems/ExpIntervalWAttained.lean)

**`Prop. 2` — the input as if constant.** The proposition evaluates `(Ir + W*(r))V`, one matrix
applied to one element of `V`, which is the contribution of an input that is constant over the
step. A varying input gives `∫₀ʳ e^{Aτ}v(r - τ)dτ`, and that set is not inside it. At the point
matrix `A = [[0, 0], [1, 0]]`, so that `A² = 0` and every order from three up vanishes, and
`V = [-1, 1] × {0}`, the input `v(t) = (w(t), 0)` with `w = 1` on the first half of the step
and `-1` on the second reaches `x_p(r) = ∫₀ʳ e^{Aτ}v(r - τ)dτ = (0, r²/4)`; the printed set is
`{(rv₀, ½r²v₀)}` widened by `E(r)rV`, a box of half-width `O(r^{p+2})`, and once `r` is small
it holds no point whose first coordinate is near `0` and whose second is near `r²/4`. The proposition also claims the
set over the whole interval `[0, r]`, which needs `0 ∈ V`. Althoff's thesis replaces it by
`Σ_{i=0}^η (Aⁱr^{i+1}/(i+1)! U) + E(r)rU` with `0 ∈ U` (its Thm. 3.1 and Prop. 3.3), which is
what the tree proves, at a single matrix. The row stays `—` because the interval-matrix case is
not formalized, so no class is given and no counterexample is written.

**`Thm. 3` — the remainder.** The printed proof writes `E(t) - (t/r)E(r)` as
`⟨-1, 1⟩(φ(t) - (t/r)φ(r))`, pulling one `⟨-1, 1⟩` out of two independent remainders; as
independent interval matrices the difference has radius `φ(t) + (t/r)φ(r)`, twice what `E(r)`
allows at `t = r`. The bound holds for another reason, which `ExpDiff` proves at a single
matrix: the two remainders share `Aⁱ` term by term, so they are one series, and
`|tⁱ - t rⁱ⁻¹| ≤ rⁱ` bounds it by `Σ_{i>p} ‖A‖ⁱrⁱ/i!`.
