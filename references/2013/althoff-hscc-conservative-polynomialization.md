# Reachability Analysis of Nonlinear Systems using Conservative Polynomialization and Non-Convex Sets

M. Althoff. "Reachability Analysis of Nonlinear Systems using Conservative
Polynomialization and Non-Convex Sets". HSCC 2013.

**Source:** https://mediatum.ub.tum.de/doc/1283922/39133.pdf (read directly with a custom PDF-content-stream text extractor since no PDF rasterizer was available in this environment — poppler/pdftoppm is not installed, so the Read tool's PDF-page mode is unavailable)  
**Inventory:** confirmed (full 10-page paper read)

Conservative polynomialization: abstracting a nonlinear field to second order
rather than first, so the abstraction error shrinks with the *square* of the
set. `NonlinearSys.deltaReach` and the polynomial abstraction error around it.

## Findings

**Sec. 4.2's `varInputs` encloses `Eq. 7`'s set; it does not equal it, though the section prints
`=`.** The printed line is `V∆(τs) = varInputs(Rz(ts), R∆z(τs), U∆, B, D) := B ⊗ U∆ ⊕ ½(mu(D,
Rz(ts), R∆z(τs)) ⊕ mu(D, R∆z(τs), Rz(ts)) ⊕ sq(D, R∆z(τs)))`. A Minkowski sum lets each summand
choose its operands for itself, where one member of `Eq. 7` chooses one `z` and one `z∆` and uses
that pair in all three quadratic terms, so only `⊇` holds. One dimension is enough to see the gap:
at `o = n = 1`, `D = [1]`, `B = 0`, `Rz = R∆z = [-1, 1]` and `U∆ = {0}`, `Eq. 7`'s set is the image
of `(z, z∆) ↦ z·z∆ + z∆²/2` over the square, which is `[-0.5, 1.5]`, while the four-term form is
`½([-1, 1] ⊕ [-1, 1] ⊕ [0, 1]) = [-1, 1.5]`. `varInputs_outer` therefore claims the containment and
not the equality, which is all the certificate design spends anyway.

**`Eq. 7` and Sec. 4.2 disagree about which set `z` ranges over.** `Eq. 7` writes `z ∈ R(τs) × U`,
but the function it quantifies, `v∆(z∆(t), z(ts), u∆(t))` in `Eq. 5`, takes the value *at the point
in time* `ts` in that argument, and Sec. 4.2 duly passes `Rz(ts) = R(ts) × U`. Since `R(ts) ⊆
R(τs)`, `Eq. 7` is the looser of the two readings, and the `R(τs)` reading's `varInputs` encloses
the `R(ts)` reading's — `varInputs_mono` (`Theorems/VarInputsMono.lean`) is monotone in both set
arguments, so the containment carries straight through. `varInputs_outer` takes the three ranges as
arguments rather than naming them, so it proves each reading at that reading's own sets and does
not have to choose.

**`Prop. 2`'s stretch factor is read as `1+|γⱼ|`, not the printed `1+γⱼ`.** Left unsigned, `1+γⱼ`
can undershoot the magnitude a coefficient in `[-1,1]` sharing that generator with `g^{(i)}`'s own
`[-1,1]` factor actually needs — the achievable range of `βⱼ+γⱼβᵢ` over `βⱼ,βᵢ∈[-1,1]` has
half-width `1+|γⱼ|`, which is what `1+γⱼ` understates whenever `γⱼ<0`. `dropIndepStretch` uses the
signed-safe `1+|γⱼ|` throughout, which only widens the enclosure.
