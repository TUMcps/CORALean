# Reachability Analysis of Nonlinear Differential-Algebraic Systems

M. Althoff and B. H. Krogh. "Reachability Analysis of Nonlinear Differential-Algebraic Systems". IEEE Transactions on Automatic Control, 59(2):371-383, 2014.

**Source:** https://mediatum.ub.tum.de/doc/1281529/document.pdf (the authors' manuscript in TUM's repository mediaTUM, on the journal template with the venue left blank, 13 pages, read in full; text extracted with `pypdf`). The typeset article (doi:10.1109/TAC.2013.2285751, IEEE TAC 59(2):371-383, February 2014) was not reachable, so numbers are the manuscript's. CORA's `@nonlinDASys` headers give the year as 2013, the online-first date; `@nonlinearSysDT/private/priv_linError_mixed_noInt.m` gives the published volume, issue and pages.  
**Inventory:** confirmed (against the manuscript: Definition 1, Propositions 1-3, Lemmas 1-2, Theorem 1, Corollary 1 and Algorithm 1, each with its own counter; Equations 1-26, of which 25-26 and Table I are the example's model; Sec. VII is the example)

The algorithm behind CORA's `nonlinDASys` reachability: linearize the semi-explicit index-1 DAE
`ẋ = f(x, y, u)`, `0 = g(x, y, u)` at a point, solve the linearized constraint for the algebraic
deviation through `F⁻¹`, and get a linear differential inclusion in the differential variables
whose input carries the linearization error (Eqs. 12-16, Prop. 1); the algebraic variables are
recovered correlated with the differential ones (Prop. 2), and the error is enclosed through
interval Hessians by a quadratic map that needs no interval arithmetic (Prop. 3, Thm. 1,
Cor. 1). Everything from the Taylor expansion to the error enclosure is formalized, and the
overall algorithm with its soundness for runs that stay in the region the errors are taken over.
The remainder sets of Eqs. 10, 11 and 20 take one Lagrange point `ξ` for all rows, which is false; one per row, as Eq. 8 has it, is right, and every later step holds with
it. CORA's `nonlinDASys` adds `C F⁻¹` times the algebraic error where Cor. 1 subtracts it
([`nonlinDASys` `linReach_adaptive`](../coverage/contDynamics/nonlinDASys.md)).

**`Eq. 10`, `Eq. 11`, `Eq. 20` — one Lagrange point for all rows.** Eq. 8 is the mean value
theorem row by row: `fᵢ(z) - fᵢ(z*) - ∂fᵢ/∂z(z*)ν = ½νᵀH^{d,(i)}(ξ⁽ⁱ⁾)ν` with `ξ⁽ⁱ⁾` on the
segment, each row its own. Eqs. 10, 11, 20 (and 12, 15 after them) write the remainder as the
set `{½σ | σᵢ = νᵀH^{d,(i)}(ξ)ν, ξ ∈ R^z, ν ∈ R^z_Δ}`, one `ξ` for all `i`. That set can miss
the remainder: `f(x) = (p(x₁), q(x₁))`, `p = x²/2 - x³/3 + x⁴/12`, `q = x⁴/12`, so
`p'' = (1 - x)²` and `q'' = x²`; on `R^z = [-½, 1]²` at `z* = 0` and `z = (1, 0)` the remainder is
`(1/4, 1/12)`, while `½ν₁²((1 - ξ₁)², ξ₁²) = (1/4, 1/12)` forces `2ξ₁² + 2ξ₁ - 1 = 0` and, as
`ν₁² ≤ 1`, `ξ₁ ≤ ⅓`, which have no common solution in `[-½, ⅓]`
([`SharedLagrangePoint.lean`](../../src/CORALean/ContDynamics/NonlinDASys/Counterexamples/SharedLagrangePoint.lean)).
The rest of the paper is unaffected: Eq. 23 bounds each row by the set of its Hessians
separately, and `Prop. 3`, `Thm. 1` and `Cor. 1` enclose every row at any matrix of its
interval, so the computed `L` holds the remainder either way
([`LinErrorOuter.lean`](../../src/CORALean/ContDynamics/NonlinDASys/Theorems/LinErrorOuter.lean)).

**`Prop. 1` — confinement.** The proof bounds `ẋ` for `x ∈ Rᵈ(τ_k)`, `y ∈ Rᵃ(τ_k)`, the sets
the abstraction is used to compute, and never shows that a solution stays in them over `τ_k`.
The formalization takes it as a hypothesis on the run, as the tree's other conservative-
linearization theorems do.

**`Cor. 1` — the proof's sign.** The statement has `L_c = ½(d - CF⁻¹e, H - CF⁻¹V)`; the proof
ends "`L_c ⊆ (d + CF⁻¹e, H + CF⁻¹V)`", which drops the `½` and flips the sign. The statement is
what follows from Eq. 15's `σ - CF⁻¹φ`, and what is proved. CORA's `nonlinDASys` computes the
proof's `+` ([`nonlinDASys` `linReach_adaptive`](../coverage/contDynamics/nonlinDASys.md)).

**`Alg. 1` — the horizon, the region and the loop bound.** Three things the listing leaves open
are supplied. The `while t_k < t_f` loop steps by `r` and stops at the first `t_k ≥ t_f`, so unless
`t_f` is a multiple of `r` its last window leaves `[0, t_f]`, where a run need not exist; the
formalization takes `t_f = K r`, and `K ≥ 1`, since at `t_f = 0` the loop does not run and
`R_union` is empty rather than `R(0)`. The soundness is for runs that stay, over each window, in a
region `R^z` over which the errors `L` the loop computes hold every consistent point's
linearization error: `Prop. 1`'s assumption, which the loop checks (`L ⊆ L̄`) on sets computed
under it and never establishes, so `LinPoint.Certifies` is a hypothesis of `reach_outer` as it is
of `initReach_outer`. The `repeat` loop of lines 4-10 has no stated bound on its passes, and its
exit `L ⊈ L_max` hands over to the split with errors that were never contained in the assumed
ones, which is why only the exit `L ⊆ L̄` passes a certificate from `L` to `L̄`. `reach` takes a
`fuel`, the result `none` where it runs out, and the splits recurse on `t_f - t_k` from `L = {0}`
and `R_union = ∅` exactly as lines 13-14 print them.
