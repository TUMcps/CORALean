# Automatic Abstraction Refinement in Neural Network Verification using Sensitivity Analysis

T. Ladner and M. Althoff. "Automatic Abstraction Refinement in Neural Network
Verification using Sensitivity Analysis". HSCC 2023.

**Source:** https://mediatum.ub.tum.de/doc/1710698/1710698.pdf (PDF; custom-embedded-font glyph codes decoded via the PDF's own ToUnicode CMaps)  
**Inventory:** confirmed

Refining a network's abstraction where it is loose, guided by a sensitivity
analysis. `NN.Definitions.RefinableNetwork`, the schedule, and the theorems that say
refining only tightens. §3's `sort`, `merge`, `sortPlus` and `Alg. 2` are
operations of `PolyZonotope/Real`, beside `PolyZonotope.evalPoly`, which is
Horner's rule and a different route to the same value; of `Alg. 2` what is
proved is that it computes the polynomial and leaves the exponent matrix
sorted, and no generator count or running cost is claimed for it.

## Findings

**HSCC'23 abstraction refinement.** Minor: (i) convergence needs a Lipschitz bound on every network tail; (ii) sensitivity analysis needs differentiability per layer, and differentiability of the network's evaluation does not suffice — the linked `EvalDifferentiable.lean` proves the converse direction only (`Chain.differentiableAt_eval : c.DifferentiableChain x → DifferentiableAt ℝ c.eval x`); the "does not suffice" half is the ReLU-then-zero-map argument and is not formalized; (iii) `Prop. 3.3`'s `merge` joins equal exponent columns and nothing else, so it leaves the all-zero column `Def. 2.4` forbids as well — the result is sorted but not regular in general, though no such column arises in `Alg. 2`; (iv) `Prop. 2.12` writes `PZ₁ × PZ₂ =` for a set that shares the dependent factors *and* the first q₁ independent generators, so it is a subset of the Cartesian product rather than the product — as `Prop. 3.4`'s "Minkowski sum" is a subset of the Minkowski sum, both being pairings at one factor vector. [`EncloseAtInflate.lean`](../../src/CORALean/NN/Theorems/EncloseAtInflate.lean), [`EvalDifferentiable.lean`](../../src/CORALean/NN/Theorems/EvalDifferentiable.lean), [`MergeColInjective.lean`](../../src/CORALean/ContSet/PolyZonotope/Real/Theorems/MergeColInjective.lean), [`ExactCartProdPoint.lean`](../../src/CORALean/ContSet/PolyZonotope/Real/Theorems/ExactCartProdPoint.lean)
