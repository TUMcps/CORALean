# others/powerSystem2cora

CORA files of `converter/powerSystem2cora/`, one row per `.m` file however deep (`private/` helpers have none), and where CORALean answers them. Conventions, states and the out-of-scope reasons are in [../README.md](../README.md). The group `others` is shown in the paper only as one bar, so there is no per-class figure.

**CORALean counterpart:** none.

| Method | State | In CORALean | Note |
|---|---|---|---|
| `loadPowerSystemCase` | out-of-scope | n/a — io/conversion-to-matlab-objects | loads a power-system case file |
| `powerSystem2cora` | out-of-scope | n/a — io/conversion-to-matlab-objects | power-system case to a CORA nonlinear DAE system, generating a MATLAB file |
