## Details

**`expmDifferentAlgorithms` — the remainder.** The constructor `intervalMatrix(C,D)` is
`[C-|D|,C+|D|]`, so this is the point `ones(n)`, and `E = E*factor` adds the constant
`factor*ones(n)` to the series instead of `[-factor,factor]`. `priv_taylorSeries`,
`priv_hornerTaylorSeries` and `priv_scalingSquaringHornerTaylorSeries` add it, and
`expmDifferentAlgorithms(intMat,maxOrder,0|1|2)` and `expmTaylorHornerScaling` (styles `0`, `1`,
`2`) call them. The result for a point matrix has zero width and is not `exp(A)`, nor does it
contain it.

**`expmDifferentAlgorithms` — the example.** `intervalMatrix(-1)` (the `1 x 1` matrix `-1`) with
`maxOrder = 2` and style `0`: `alpha = 1`, the partial sum is `1 - 1 + 1/2 = 1/2`,
`factor = (1/6)/(1 - 1/4) = 2/9`, and the result is the point `13/18 = 0.7222` while
`exp(-1) = 0.3679` (Horner gives the same). The non-degenerate branch is right. Unsound: an
enclosure of `exp(A)` that excludes it.

**`expmDifferentAlgorithms` — the model.** Modelled as `MatExp.taylorPointRemainderCora` for a
`1 x 1` matrix. The theorem shows the point `13/18` above `exp(-1)` (read from the source, not run).

**`randPoint` — the draws.** `intervalMatrix(0,1)` (the entry `[-1,1]`): `'standard'` gives values
in `[-1,0)` and `'extreme'` gives `+-1/2`. Every sample is inside the box, so a containment test
does not see it, but the sampling that falsification and the tests use covers half of each entry and
never a vertex. A wrong answer.

**`randPoint` — the model.** Modelled as `Interval.randPointStandardIntervalMatrixCora` and
`Interval.randPointExtremeIntervalMatrixCora`, one entry. The theorem shows no `'standard'` draw
above the center and no `'extreme'` draw at an endpoint (read from the source, not run).
