# others/@partition

CORA methods of `discrDynamics/@partition/`, one row each, and where CORALean answers them. Conventions, states and the out-of-scope reasons are in [../README.md](../README.md). The group `others` is shown in the paper only as one bar, so there is no per-class figure.

**CORALean counterpart:** `GridPartition` (`DiscrDynamics/GridPartition/`), written over ℝ: a box cut by dividers, cells numbered from `1` with the first dimension fastest and `0` for the outside.
