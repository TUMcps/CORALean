# contSet/@zoo

CORA methods of `contSet/@zoo/`, one row each, and where CORALean answers them. Conventions, states and the out-of-scope reasons are in [../README.md](../README.md).

**CORALean counterpart:** `Zoo` (real layer only): an optional Taylor model (CORA's `taylm(int)`) and an optional interval (`interval`), each enclosing one function over the normalized box. CORA's other members are not modelled: `taylm(bnb)`, `taylm(bnbAdv)` and `taylm(linQuad)` differ from `taylm(int)` only in the range bound `interval` reads, and `affine(·)` is a Taylor model of order one (R-AFF), which the single Taylor model slot cannot hold beside `taylm(int)`. Only the zoo-by-zoo operand forms are covered; the `double` and `interval` operand forms are not.
