# Float definitions that are only `X.nominal.op args` on purpose (CONTRIBUTING, "Float
# definitions earn their name"; issue #154).
#
# `scripts/check-float-wrappers.py` refuses any other such definition: the exact operation at
# `nominal` is already written `X.nominal.op args`. An entry says why the name is kept. The list
# only shrinks, and an entry whose definition is gone or no longer a bare wrapper is reported as
# stale.
#
# One line per definition: `<path>::<name>  <reason>`. A reason starts with one of:
#   class:    the `construct` of a representation without an error box, which the `ContSet`
#             instance and every `X.construct` in a statement resolve through by dot notation.
#   meaning:  what a stored value claims, the hypothesis its theorems share, as `construct` is a
#             set's.
#   name:     a `Real.op (toReal… x)` read at what the floats denote, kept because the call sites
#             are statements that would otherwise spell the conversion out each time.
