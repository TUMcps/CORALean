# Allowlist for `noncomputable` where the rules do not already allow it.
#
# `check-conventions.sh` rejects every `noncomputable` declaration that is not
# in the `Real/` layer of a `ContSet/` representation (rule 1), not the ℝ model
# of the scalar interface under `Global/Float/Instances/Real/` (rule 2), not an
# `aux_*` declaration (rule 3) and not in a `Definitions/` file, which says what
# an object means and is never run, unless its name is listed here with a
# reason. Under a `/Float/` path there is no listing: only rule 3 excuses a
# float declaration, because the whole point of the float layer is that it
# runs.
#
# One line per entry: `<name>  <reason>`, the name exactly as `check-
# conventions.sh` reads it — the declaration's own written name in full,
# dotted prefix and all (`LinearSys.reach`, not `reach`), and with every byte
# kept, including a non-ASCII one (`norm₂`, not `norm`): two representations'
# same-named operations are two distinct declarations and get two distinct
# entries. A declaration written with no dotted prefix is listed as that bare
# name, which is still one specific declaration's spelling. A reason starts
# with one of:
#   spec:      a specification object — a reachable set defined by
#              trajectories, a norm, a Hausdorff distance, a real-valued
#              certificate — never meant to run.
#   cost:      an asserted running cost under `Complexity/Time/`.
#   real-layer: part of the real (ℝ-valued) half of a representation, or an
#              ℝ-only part of a directory otherwise written over the scalar,
#              or reached only from such a definition and nothing runnable.
#   pending #N: an algorithm with no float refinement yet, for a reason
#              `check-conventions.sh`'s own comments do not repeat per entry;
#              see the reason text on each line for which blocker. `#N` is
#              the GitLab issue the blocker is tracked under.
#
# An entry that stops matching any `noncomputable` declaration is an error —
# "stale allowlist entry" — so this list only shrinks honestly.
#
# pending #1: a continuous-time algorithm at `r : ℝ` and the real matrix
# exponential with no float counterpart yet. The float `Interval` is indexed by
# its ambient type, so `Interval (Mat 𝕋 m n)` and its operations exist; each
# line names what its own counterpart still needs. A `real-layer:` line on a
# continuous-time name cites the float definition that runs in its place.
