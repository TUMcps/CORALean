# Fields that a discrete-time class and its continuous twin do not share, with the reason.
# Read by scripts/check-dt-twins.py (#172), run from check-conventions.sh: the fields of
# `structure <X>DT` and `structure <X>` are compared by name, and a difference not listed here
# is a finding. One line per field, `<X>DT.<field>  <reason>`; the list only shrinks, and an
# entry that no longer matches a difference is reported as stale.
#
# A reason starts with one of:
#   dt:     the sampling time, which a continuous system has no use for.
#   CORA:   CORA's own two classes differ in this parameter too.
#   pending: a mismatch that is not intended, with the issue that fixes it.

LinearSysDT.dt  dt: the sampling time of CORA's `linearSysDT`; `linearSys` has none
NonlinearSysDT.dt  dt: the sampling time of CORA's `nonlinearSysDT`; `nonlinearSys` has none
