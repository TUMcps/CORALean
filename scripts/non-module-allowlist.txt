# Files under `src/` that stay non-module, outside `Examples/` (which stays
# non-module whole: `#eval` in a module needs `meta import`).
#
# `check-conventions.sh` refuses any other file that does not open with
# `module` (CONTRIBUTING, "The module header"), and reports an entry here that
# is a module now, or gone, as stale: the list only shrinks.
#
# One line per file: `<path>  <reason>`. A reason starts with one of:
#   unexposed:  a proof unfolds a definition that core or Mathlib does not
#               expose to modules, so it fails once the file is a module.
#   imports:    the file imports a file on this list, and a module cannot
#               import a non-module. It becomes a module once those do.
