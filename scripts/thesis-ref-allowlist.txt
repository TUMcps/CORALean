# Files whose `## References` still names a thesis (the rule: cite the paper).

# `scripts/check-thesis-refs.py` refuses any other: a thesis reproduces results that first appeared
# in papers, and the paper is cited with its own numbering. A file lands here while no paper we hold
# states the result its entry stands for; once one does, the entry moves to that paper and the line
# is deleted. One path per line, grouped under the reason as a comment. An entry that matches no
# flagged file any more is reported as stale, so the list only shrinks.
